# 瑶光 · 公开只读数据通道

> **当前状态：未发布（NOT READY）**。本仓库目前不提供可供瑶光 App 自动导入的历史记录或模型。

此仓库仅用于在完成来源核验、审查和独立数字签名后，以 **HTTPS 只读** 形式向瑶光 Android 客户端提供公开开奖结果。双色球（SSQ）和大乐透（DLT）的发布包、版本序列与核验必须严格独立。

## 预定的客户端固定路径

- `v2/ssq/current.json` — **尚未创建**，正式发行前不允许视为可用
- `v2/dlt/current.json` — **尚未创建**，正式发行前不允许视为可用

**这两个路径不会放置未经签名的占位数据**，以免被错误识别成真实开奖发布源。只有经过完整验签与官方来源审查的数据，才能成为有效的 `current.json`。

## 发布与安全边界

1. 公开仓库不得保存个人购彩记录、预测号码、盲测锁定档案、备份、账户凭据、GitHub Token、任何私钥或私有训练输入。
2. 官方开奖结果须按期核对**实际开奖日期、期号、球号**；网页的公告/发布日期不得替代实际开奖日期。来源冲突时停止发布，不覆盖既有历史。
3. 发布端使用与 Android APK 安装签名**不同**的独立数据发布私钥签名；**私钥不进入此仓库或客户端**。客户端只内置审核通过的发行公钥。
4. 客户端须先验签，再检查彩种、版本/防重放序列、有效期、历史连续性与旧号码不变等规则，才能原子写入本机。失败则保留现有数据和锁定预测。
5. 对历史数据的研究或回测结果**不证明能够预测随机开奖**；未完成发布和真机验收前，本仓库不能被当作可用服务。

## 仓库用途

这里仅作为批准后的**静态公开内容分发点**。官方来源核验、双彩独立研究和私有审查记录在独立私有环境进行；将资料发布到这里需要专门的审核与发布门槛。
